# ACE 股票研究 / 超短线工作流

## 固定链路

实时行情 / 资金 / 公告 / 板块数据
↓
老师研究判断
↓
老手观察框架（动态校验，不是僵化代码）
↓
老师形成最终判断
↓
小妍
↓
小群可发送话术

## 老手观察框架

- 板块先锋 / 中军 / 连板梯队
- 竞价 → 开盘情绪
- 弱转强的板块、情绪、个股条件
- 炸板与后排蹭流预警
- 涨停股与被砸股对照
- 位置、预期差、量价、资金连续性、退出路径

## 工作约束

- “推2支票 / 推3支票”默认按 A 股超短线处理，不重新询问市场类型。
- 先核验实时证据，再由老师判断；数据不足时降级为研究候选，不硬凑票。
- 老师拿到票后交给小妍；小妍负责小群内温暖、简洁、条件式话术。
- 收盘后对当日候选做 D+1 / D+2 复盘，区分当时证据与事后结果，用于发现判断不足，不把复盘写成固定选股规则。
- 不承诺收益、不自动下单、不把研究候选包装成确定性推荐。

## 核心认知

- A 股不是可以机械套用其他市场经验的同质化市场；超短线判断必须建立在对 A 股情绪、题材、资金博弈、涨跌停约束和筹码结构的独立理解上。
- 指标、接口和量化因子只提供证据与校验，不能替代老师自己的判断；候选进入交付前，必须说明为什么值得做、预期差在哪里、什么条件下失效。
- “敢于下单”不是冲动追高，而是在证据、赔率、仓位和退出路径清楚后，敢于执行自己的判断；看错时同样要敢于止损和退出。
- 每日复盘的目的，是识别老师自己的认知缺口、时机错误、位置误判和风险降级失灵，持续学习，不把复盘冻结成僵化代码。

## 四维判断框架（固化）

- **历史**：相似题材、政策周期、龙头高度、连板梯队和过去的强弱转化规律；不以事后结果倒推当时判断。
- **政治**：政策方向、监管态度、产业战略、会议和官方信号；区分政策 headline 与资金实际传导。
- **盘面**：指数、板块宽度、先锋/中军/梯队、竞价、开盘承接、分时、量价、资金、涨停与炸板。
- **市场情绪**：进攻、分歧、退潮、修复，连板高度、涨停/跌停、炸板率、核按钮和亏钱效应。

四维不做机械平均分。历史与政治提供背景和预期差，市场情绪决定风险开关，盘面负责验证资金是否真的认可，最后由老师结合 A 股独特理解形成判断。

四维框架的理论与验证说明见 [ACE_STOCK_THEORY_AND_VALIDATION.md](ACE_STOCK_THEORY_AND_VALIDATION.md)：当前定位为有机制解释的研究假设，需通过点时回放、样本外、跨状态切片和反例挑战，不能把操作经验冒充公开验证过的定理。
