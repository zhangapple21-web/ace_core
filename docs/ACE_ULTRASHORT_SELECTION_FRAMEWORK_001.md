# ACE 超短线选股框架（研究候选版）

更新时间：2026-08-31  
状态：`RESEARCH_ONLY`，尚未接入 Advisor、Risk 或 Telegram

## 一、外部方法考古的结论

这次只吸收可解释、可回放的部分，不把任何交易员的宣传页或单次成绩当作收益证明。

- Minervini 的公开方法强调趋势结构、供需和实时风险管理；可吸收“先判断位置和失效，再谈强势”的顺序。其官网是商业介绍，不构成独立业绩验证。
- O'Neil/IBD 的 follow-through 思路强调大盘环境先于个股突破；可吸收“指数和市场宽度不配合时降低出手”的原则。
- Jegadeesh 与 Titman 的论文验证了 3—12 个月维度的动量，但这不是 A 股早盘超短策略的直接证明；只能说明“相对强弱”值得作为一个研究维度，不能直接搬用持有周期。
- Lo、Mamaysky、Wang 的技术分析研究把形态识别程序化，并发现部分形态具有增量信息；同时也说明形态必须规则化、统计化，不能凭肉眼讲故事。
- 上海证券交易所投教资料明确了科创板 20% 涨跌幅及适当性要求。A 股涨跌停、T+1 和板块交易权限会直接影响超短的可成交性与隔夜风险，必须作为执行约束，而不是事后免责声明。

## 二、ACE 自己的五层判断

### 1. 先定市场状态

记录上证、深证、创业板的方向、涨跌家数、成交额变化和主线板块广度。指数明显走弱、热点只剩少数涨停或板块出现快速退潮时，候选数量可以降到 0—1 只。

### 2. 位置优先，涨幅靠后

候选先经过“反追涨”筛选：

- 当日上涨约 5% 以上，默认不做主选；上涨约 8% 以上、接近涨停、日内振幅约 8% 以上或已触及近期压力位，只能进入观察池。
- 优先首段启动、平台突破后的第一次回踩、或板块内尚未充分扩散但量价刚转强的股票。
- 当前价与压力位之间要留有空间；距离失效位太近或只能在涨停板排队的股票，视为不可执行。

#### 2.1 4–5% 早期转强车道（新增固化规则）

4–5% 的当日涨幅不再自动视为“涨多了”。它可以是首段启动或第一次确认后的可参与区间，但必须满足：

- 仍处于首段/首次回踩，而不是尾段加速或接近涨停；
- 板块至少有两个可交易代表同步，不能只是单股脉冲；
- 竞价/开盘或分时承接有效，拉升放量、回踩缩量且价格有推进；
- 距离压力位和失效位仍有可执行空间，流动性足够；
- 明确写出“确认后参与”和“失效即撤销”，参考仓位随波动下降。

因此，4–5% 只是“可以进入主动核验”的价格状态，不是买入理由，也不是收益预测。若出现尾段加速、放量滞涨、板块掉队或失效距离过小，只能观察或放弃。

#### 2.2 提前识别的定义

ACE 可以做的是条件式的“提前识别”：在突破完全确认前，发现平台收敛、相对强于板块、竞价/前五分钟承接、回踩缩量回收、近 1–3 日资金连续性等证据组合；不能把它写成“必涨”或确定性预测。每个提前识别卡必须有 `forecast_evidence`、`confirmation`、`invalidation` 和验证窗口。

### 3. 量价和板块必须互相确认

- 量能放大应伴随价格有效推进，不能只是高换手长上影。
- 用至少三个可交易的板块代表标的和板块指数交叉观察，区分“普遍走强”和“一只股票独立脉冲”。
- 资金流只作辅助证据；没有清晰来源、时间戳或独立组时，不写成机构/游资事实。

### 4. 事件与反方证据

公司公告、行业催化、政策和隔夜消息必须能追溯到公开来源。每个候选同时写一条反方检查：指数转弱、板块跟风不足、冲高回落、量价背离、公告无法确认或数据源不同步。没有反方证据时，结论最多为 `UNKNOWN/RESEARCH_ONLY`。

### 5. 条件式计划和退出

每只候选固定输出：观察/介入区、强势确认、失效条件、压力观察位、参考仓位、不能追价的情形。失效条件采用结构位或成交行为，不用“必涨”“稳赚”“配合拉升”等宣传语。

## 二点五、资金蓄势/非过热候选因子

吸收 XQ 短线中小型股策略的可解释思想：先筛选流动性，再寻找近期未过热、且有大资金提前布局迹象的标的。台股“前十大综合券商买超”没有 A 股等价物，不能直接用龙虎榜营业部或单一数据商的主力净流入替代；在 ACE 中只记录为研究候选：

```text
流动性通过 + 近期不过热 + 当日/近1–3日资金连续性
+ 当日盘口承接 + 板块仍在加强 + 次日路径明确
```

资金因素以当日盘口和近 1–3 日为主，5 日数据只作背景；资金净流入/流通市值、资金变化对应的价格响应和 5 日最大振幅可作为待验证指标。缺少可追溯分母、时间戳或独立来源时标记 `UNVERIFIED`。原文章宣称的固定参数、7% 止盈止损和历史胜率不作为 ACE 事实，必须经过 A 股点时数据、滑点、手续费、涨停无法成交和样本外回放后才可评价。

## 三、进攻梯度、排序和数量规则

ACE 不以“每天抓涨停”为目标，但也不能因风险控制而系统性退化成防守选股。市场环境和证据链允许时，默认候选结构为：

- 一只高弹性进攻候选：可接受约 `3%–7%` 当日涨幅和更高波动，必须有板块共振、主动承接、量价确认、次日路径和可控失效距离；仓位通常 `1%–2%`，验证窗口缩短到当日尾盘至次日。
- 其中 `4%–5%` 优先作为“早期转强/确认后仍可参与”观察带；只有通过上述早期转强车道，才允许保留为进攻候选。
- 一只可参与的平衡候选：波动相对可控，但仍需具备启动/首次回踩结构和 1–2 日确认空间；不能用大盘防守股替代超短线机会。

若情绪、板块或盘口不支持，允许两只都降级或输出 `NO_SUITABLE_SETUP`；不能为了追求涨停放宽数据和风险门，也不能为了规避波动机械只选低弹性品种。

研究排序建议（适用于 1–2 日验证的动态基准）：

```text
市场情绪/指数环境 20%
板块强度/轮动位置 20%
竞价/开盘承接   20%
分时量价/换手    20%
当日及近1–3日资金 15%
次日预期/退出    5% + 硬门
```

分数只是研究排序，不是概率或收益率；位置、可交易性、失效距离和次日路径是硬约束。默认组合为“一只板块弹性 + 一只普通主板可参与标的”，但只有通过可成交性和反方检查才保留。没有合格设置时输出 `NO_SUITABLE_SETUP`，不为凑数而推荐。

## 四、交易性升级：机会、信念与决策终点

ACE 的研究交付定位为 `Daily Trading Intelligence`：每天识别值得用户认真审阅、可能值得主动承担可定义风险的机会；ACE 不持有账户，也不替用户承担真实仓位风险。用户保留最终过滤权，但这不改变证据真实性、时间戳、独立来源、可成交性和退出条件要求。

`NO_SUITABLE_SETUP` 仅表示没有值得承担风险的非对称短线机会，不等于没有“百分之百舒服”的股票。数据暂缺、来源冲突或实时性不足单独标记 `DATA_UNAVAILABLE`/`RESEARCH_ONLY`，不能伪装成市场没有机会。

候选增加研究字段：

```text
attack_grade: A+ | A | B | C | D
conviction: LOW | MEDIUM | HIGH
opportunity_quality / expected_payoff / invalidation_distance / liquidity
decision_endpoint: 进入执行/验证，后续只记录强化、失效或退出
```

`A+` 为主线核心、强承接、高赔率；`A` 为高赔率且证据较完整；`B` 为有机会但需要人工确认；`C` 为普通观察；`D` 为防守/不占用超短算力。超短线默认只把 `A+/A/B` 放入核心研究，不用 `C/D` 凑数。`conviction` 表示证据是否达到主动判断阈值，不是胜率；赔率字段用于解释非对称性，不得未经回测直接做概率乘法。

从 `ace.ultrashort_factor_profile.v2` 起，候选卡还必须把以下两条线分开记录：

```text
opportunity: score / attack_grade / conviction
risk: risk_level / risk_score / invalidation_distance / liquidity
```

`conviction=HIGH` 表示证据链足以进入主动验证，不代表低风险；`risk_level=HIGH` 也不自动把机会降成 C/D。只要交易可行性、次日路径、独立新鲜证据和失效/退出条件都通过，系统允许出现“高风险 + A/A+”的进攻卡，并用更小仓位、更短验证窗口表达风险，而不是用保守等级掩盖赔率。反过来，分数高但次日路径或失效条件未知，只能停在 `WAIT_FOR_CONFIRMATION`，不得写成执行建议。

TN6 只进入 `tn6_prior` provenance 字段。未取得公式文本或点时历史回放前，100 个文件的命中/文件名/大小/hash 都不能改变六因子分数；只有独立回放证据通过后，才允许另行提交先验贡献的研究变更。

当核心证据达到阈值后，执行“决策终点原则”：停止无休止追加次要分析，转入执行/验证记录；只要强化、失效或退出条件发生就更新，不因一个不改变核心假设的次要疑点自动降级。机会优先于安全感，但高波动只有在逻辑清楚、流动性足够、承接真实、退出路径明确且赔率非对称时才可被视为可控风险。

## 五、验证计划

在接入任何自动候选前，使用至少 20 个历史交易日做冻结回放，记录：触发时点、理论成交率、滑点、次日可退出性、失效触发率、假突破率、板块同步率和最大连续亏损。回放结果与实时结果分开保存，不能把纸面回测当作生产准入。
