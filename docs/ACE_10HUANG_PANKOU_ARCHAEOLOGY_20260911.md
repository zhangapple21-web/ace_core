# ACE 拾荒网盘口栏外部方法考古

更新时间：2026-09-11（Asia/Shanghai）  
状态：`RESEARCH_ONLY`；只读考古和设计裁决，不安装、不抓取名单、不接入生产。  
来源栏：`http://www.10huang.cn/pankou/`（社区短线教材，不是当日荐股池）

## 1. 结论先行

拾荒网盘口栏对 ACE **有启发，但不能当荐股信号源**。

它能补的是老师审阅时已经缺的三块口径：

1. **市场状态要有周期粒度**：启动 → 分歧 → 主升 → 高潮 → 分化 → 退潮 → 冰点。这与 ACE「先定市场状态」同向，退潮/冰点应对齐 `NO_SUITABLE_SETUP` 或把候选压到 0–1。
2. **避雷比选股更值钱**：假强连板、尾盘偷鸡板、水下翻红诱多，应进入现有反方证据清单，而不是变成新的进攻形态。
3. **老师口吻是节奏，不是打板指令**：启动/主升才给观察空间，下降期无条件降仓或交空包；低位看逻辑、高位看情绪，高位连板看运气——这只解释「为什么今天不写卡」，不能写成买入理由。

它不能补的是选股理由本身。ACE 超短线要的是「预期差 → 确认 → 可退出」，不是「一二三板打板、四五六板接力」。网站浏览量、单票战例、口诀和营销句，都不是收益证明。

```text
拾荒网盘口栏（community_discussion / 方法考古）
        ↓ 只吸收可解释、可回放部分
ACE 已有超短线框架 / 老师审阅包
        ↓
市场状态提问、反方证据标签、审阅口吻
        ✕ 不进入 PRODUCTION_ADMISSION
        ✕ 不改 Advisor / Risk / Telegram / 订单
        ✕ 不把教材写成 market_fact
```

本轮只落这一份裁决文档。不改 `teacher_review_packet.py`、不改评分权重、不接 Telegram、不自动推送。

## 3. 外部线索逐项裁决

| 线索 | 裁决 | 只吸收什么 | 不能吸收什么 |
| --- | --- | --- | --- |
| 情绪周期划分（启动→分歧→主升→高潮→分化→退潮→冰点） | `ADAPT-CANDIDATE` | 把「先定市场状态」写细：单日情绪点 ≠ 多日周期线；退潮/冰点允许空包；高潮/分化加强反追涨 | 不把口诀阶段名写成实时标签；没有指数/涨跌家数/板块宽度硬数据时不得自称「主升」或「冰点」 |
| 「情绪是单日，周期是一段时间」 | `ABSORB` | 对齐现有六因子里「市场情绪/指数环境」与「板块强度/轮动位置」两轴，避免用一天高潮覆盖一段退潮 | 不新增第三套情绪评分，不改 `ace.ultrashort.1-2d.v2` 权重 |
| 一二三板看逻辑，四五六板看情绪，七八九板看运气 | `ADAPT` | 位置优先、涨幅靠后：低位看可追溯逻辑，高位默认观察；接近涨停/高连板不是 ACE 主选 | 不把「打几板」写进荐股卡；ACE 不是打板系统，不追求连板高度 |
| 弱转强：板块上涨预期 + 次日情绪转强预期 | `ADAPT-CANDIDATE` | 映射到「预期差 → 确认 → 可退出」和 4–5% 早期转强车道；必须有板块代表同步 | 弱转强不是买入理由，不能替代 trigger/invalidation |
| 假强连板（小盘、逻辑杂、秒板加速、途中极少换手、一换手就出货） | `ABSORB` | 作为反方证据模板：单股脉冲、逻辑不可追溯、放量滞涨/开板出货 | 不把「秒板气质」当进攻加分；个股战例不是统计证明 |
| 尾盘偷鸡板（约 14:00 后点火） | `ABSORB` | 对齐盘中时间状态机：09:45 后只跟踪确认/失效，不因尾盘点火新开主选 | 不把尾盘板写成次日溢价承诺 |
| 水下拉升翻红 / 摸板诱多 | `ABSORB` | 对齐「高开低走、冲高回落、丧失结构后再翻红」的反方检查 | 不把盘中翻红当弱转强确认 |
| 总龙 / 先锋龙 / 补涨龙 / 中军 | `RESEARCH` | 仅作板块代表股的研究标签，帮助区分主线、跟风、补涨 | 不把「总龙」写成推荐角色或 attack_grade |
| 连板接力模式、空间板、抱团、连板+趋势 | `DEFER` | 可留作自由区对照假设：节点不对就不做加速票 | 不在老师审阅卡里写打板/扫板/排板动作 |
| 封成比、竞价量能「超预期」 | `RESEARCH` | 若未来有合法竞价字段，可作为开盘承接的提问项 | 当前 quote/1m/index Phase 2 未严格准入前，不得计算实时封成比结论 |
| 烂板成妖、核按钮、换庄等江湖叙事 | `REJECT` 作为选股理由；`RESEARCH_ONLY` 作为反例词 | 只提醒老师：叙事不能替代成交与结构 | 不进入 thesis，不进入 Telegram 话术 |
| 网站浏览量、置顶战例、单票复盘图 | `REJECT` | 无 | 不是独立证据，不进 lineage，不进胜率统计 |

## 4. 与 ACE 现有能力的对齐

### 已经具备、不必另起炉灶

- `docs/ACE_ULTRASHORT_SELECTION_FRAMEWORK_001.md`：五层判断、反追涨、4–5% 早期转强、`NO_SUITABLE_SETUP` / `NO_A_TODAY`
- `docs/ACE_ULTRASHORT_PLAYBOOK_002.md`：预期差→确认→可退出；盘中时间状态机；反方证据清单；标准研究卡交给老师
- `core/teacher_review_packet.py`：最多两张 `RESEARCH_ONLY` 卡；禁止 order/buy/sell/target_price/guarantee/telegram/auto_push；缺硬证据就空包
- `core/ultrashort_factor_profile.py`：市场/板块/竞价/分时/资金/次日 权重已固化；`attack_grade`、`conviction`、`risk_level` 三轴独立
- `core/market_context_research.py`：社区讨论只产生 `UNVERIFIED_CONTEXT` 提问
- `core/tg_stock_language.py`：展示层只控表达，不创造市场事实，不把回复变成交易指令

### 映射到现有字段，而不是新模块

| 拾荒网说法 | ACE 落点 | 用法 |
| --- | --- | --- |
| 周期启动 / 主升 | 市场状态允许观察；仍需指数、宽度、板块代表硬数据 | 最多打开研究核验，不自动出卡 |
| 周期高潮 / 分化 | 反追涨审查；接近涨停只观察 | 高弹性卡必须缩短验证窗口，写清失效 |
| 退潮 / 冰点 / 下降期无条件降仓 | `NO_SUITABLE_SETUP` 或空老师包 | 不为凑两只票制造买点 |
| 板块先锋 / 中军 / 补涨 | setup C「板块二线补涨」+ 至少两个可交易代表同步 | 跟风数量快速减少则补涨逻辑失效 |
| 假强连板 / 秒板加速 / 逻辑杂毛 | `counter_evidence` | 记 `FACT` 或 `UNKNOWN`，冲突则降级 |
| 尾盘偷鸡 | 09:45–15:00 只跟踪，不新开主选 | 窗口已过应改口为次日观察 |
| 水下翻红诱多 | 冲高回落 / 结构失效后的翻红 | 不得当作弱转强确认 |
| 弱转强看次日预期 | `next_day_path` 硬门 + `trigger_conditions` / `invalidation_conditions` | 次日路径未知则 `WAIT_FOR_CONFIRMATION` |
| 老手口吻：先拍板、盯死两件事、别踩坑 | 仅展示层；老师确认前不得发群 | 不把「核按钮」「偷鸡」写成催单 |

### 建议的唯一后续研究动作（不在本轮编码）

1. 在老师审阅卡的反方证据词表中，增加可核验标签：`fake_limit_up_chain`、`late_session_ignition`、`underwater_reclaim_trap`、`cycle_ebb`。

3. 周期阶段若要结构化，必须由指数方向、涨跌家数、成交额、板块宽度推导，阶段名只是解释，不是因子分。

## 5. 老师审阅口吻：可借鉴的句子，不是话术库

可借鉴的判断顺序：

```text
今天处在周期的哪一段？
有没有可追溯逻辑，还是只是数板？
板块有没有第二只代表，还是单股脉冲？
若判断错，失效位在哪，还是只能等涨停打开？
下降期或窗口已过：空包，不硬凑。
```

必须改写后才能出现在研究卡里：

- 「打板 / 扫板 / 排板」→ 观察区、触发条件、可成交性
- 「核按钮」→ 结构或行为失效
- 「偷鸡板」→ 尾盘点火，窗口已过
- 「总龙」→ 板块代表 / 主线观察对象
- 「稳、必涨、接力赚钱」→ 删除

小群交付仍按现有手册：老师确认，小妍转发；任何现价即刻买入、保证收益的措辞都不属于 ACE。

## 6. 数据与生产边界

拾荒网没有 quote、1m、index、公告或竞价字段的 lineage。因此：

- 不能补齐实时数据；
- 不能改变 Data Health / Phase 2 Admission；
- 不能打开 Advisor / Risk / Telegram / broker；
- 不能因为「老师推片需要老手味道」就把社区口诀写入 `thesis`；
- 不能把 `01` 目录的大宗交易/顾问材料混进本裁决。

当前 A 股 `quote / minute_kline_1m / index` 的 Phase 2 仍未严格准入。没有硬数据时，老师包保持空包，结论最多 `RESEARCH_ONLY` / `DATA_UNAVAILABLE`。

## 7. 明确不做

- 不爬取、不订阅、不把拾荒网当 discovery source；
- 不把打板选股理由写入荐股卡或 `attack_grade`；
- 不安装外部战法指标，不改六因子权重，不改 `EARLY_MOVE_POLICY`；
- 不把浏览量、置顶、单次战绩写成 ACE 收益证明；
- 不自动荐股、下单、发 Telegram 或承诺客户收益；
- 本轮不改 Python 运行时。
