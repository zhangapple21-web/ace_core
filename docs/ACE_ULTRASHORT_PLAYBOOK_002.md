# ACE 超短线实战研究手册 002

更新时间：2026-08-31  
状态：`RESEARCH_ONLY`；本手册只定义研究、回放和老师审阅格式，不改变 ACE 的 Data Health、Admission、Advisor、Risk、TaskPool、Scheduler、Runtime 或 Telegram。

## 1. 这套方法从哪里来

本次公开资料考古只吸收“可解释、可记录、可回放”的思想，不把任何网站的营销页面、单次战绩或传闻当作收益证明。

| 外部思想 | 可吸收部分 | ACE 的边界 |
| --- | --- | --- |
| Minervini 公开方法 | 先看趋势结构、供需和失效位置，再谈突破 | 只作为候选排序维度；官网是商业介绍，不是独立业绩验证 |
| IBD 的 Market Trend / Follow-Through 体系 | 市场环境和宽度先于个股信号，观察上涨是否得到成交量确认 | A 股不能照搬美股日历或阈值；只保留“先定环境”的顺序 |
| Jegadeesh-Titman 动量研究 | 相对强弱可以作为可检验变量 | 论文研究的是 3—12 个月维度，不能直接证明早盘超短有效 |
| Lo-Mamaysky-Wang 形态研究 | 形态识别应规则化、统计化，避免凭肉眼讲故事 | 必须保留时间切片、规则版本和样本外结果 |
| 上交所投教规则 | 涨跌幅、交易权限、T+1 等制度决定可成交性和隔夜风险 | 制度约束是候选硬事实，不是事后免责声明 |

## 2. ACE 的核心判断：预期差 → 确认 → 可退出

ACE 不追求“猜中最强”，而是寻找仍有参与空间、并且在盘面得到确认的启动段。每个候选必须同时回答三个问题：

1. **预期差**：它为什么还没有被充分交易？位置是否仍有空间，还是已经脱离平台/压力位？
2. **确认**：指数、板块和个股量价是否同向？是多只代表同步，还是单一脉冲？
3. **可退出**：观察区、失效点和流动性是否清楚？若判断错误，能否按计划退出，而不是只能等待涨停打开？

这三个问题中任何一个无法由带时间戳的公开证据回答，结论最多为 `RESEARCH_ONLY`；不为了凑足两只股票制造买点。

## 3. 盘中时间状态机（Asia/Shanghai）

| 阶段 | 时间 | 只做什么 | 不能做什么 |
| --- | --- | --- | --- |
| 盘前假设 | 09:00–09:15 | 汇总公告、隔夜市场、主题假设；建立候选观察表 | 把隔夜消息直接写成 A 股已确认信号 |
| 集合竞价 | 09:15–09:25 | 留存竞价价格、量、指数和板块线索；标记异常高开 | 仅凭高开幅度下结论 |
| 首分钟 | 09:30–09:31 | 核对 quote、1m、index 的时间戳和来源一致性 | 使用缺字段或延迟字段计算精确买点 |
| 开盘确认 | 09:30–09:45 | 看板块宽度、代表股同步、回踩承接和量价推进；形成最多两张卡 | 追逐已经脱离观察区或接近涨停的股票 |
| 盘中跟踪 | 09:45–15:00 | 记录确认/失效和反方证据，更新老师审阅简报 | 因一条新消息改写此前事实或自动发出指令 |

实时数据在合理窗口内无法完成独立交叉验证时，切换到最近至少三个完整交易日的历史快照，并在标题显式写出“非实时”。

## 4. 候选卡的研究评分（不是胜率）

评分只用于排序，不代表概率、收益率或生产准入。所有字段都必须绑定 snapshot 时间和 source refs。为服务 1–2 日见效的超短线，现行基准把盘口和市场状态放到前面；慢变量（均线、RSI、MACD、5 日资金）只作解释和风险校验。

```text
市场情绪与指数环境       0–5，权重 20%
板块强度与轮动位置       0–5，权重 20%
竞价与开盘承接           0–5，权重 20%
分时量价与换手           0–5，权重 20%
当日及近 1–3 日资金连续性 0–5，权重 15%
次日预期与退出条件       0–5，权重  5% + 硬门
```

该权重已固化在 `core/ultrashort_factor_profile.py`（`ace.ultrashort.1-2d.v2`，profile version `v2`）。它是研究排序配置，尚无样本外收益证明；缺因子不补零，次日路径或退出条件缺失时不得进入核心观察。候选判定另行输出 `attack_grade`、`conviction` 与 `risk_level`：信念描述证据强度，风险描述波动/执行/隔夜暴露，两者不能互相冒充；因此允许“高风险 + A/A+”，但必须缩短验证窗口并保留失效条件。TN6 只作为 `tn6_prior` provenance，未完成点时回放前不改变分数。

日级输出再经过 `summarize_daily_opportunity()`：最高等级为 `A+`/`A` 时明确报告当天存在相应级别机会；若候选池最高只有 `B/C/D`，报告 `NO_A_TODAY`，不把两个 B 拼成“推荐”；没有候选卡时报告 `NO_SUITABLE_SETUP`。该判断只看机会等级，不因 `risk_level=HIGH` 自动压低 `A/A+`，从而把“机会强度、信念强度、风险等级”保持为三个独立轴。

记分规则：

- 缺失或无法核验 = `UNKNOWN`，该项不补分；
- 公开证据互相冲突 = 记为反方证据，候选降级；
- 当日上涨约 5% 以上、接近涨停、日内振幅过大或触及近期压力位，进入反追涨审查；除非出现回踩承接和二次放量确认，否则只观察；
- `4%–5%` 不自动拒绝：若属于首段启动/首次回踩后的确认，且板块宽度、承接、量价推进和失效距离均通过，进入“早期转强车道”；若是尾段加速或板块掉队，只观察。
- 评分不能抵消数据准入失败。`RESEARCH_ONLY` 不是“低分推荐”，而是证据状态。

## 5. 三种优先形态

### A. 平台突破后的第一次回踩

先有可辨认的平台或前高，突破时量价同步，随后回踩不跌回平台深处，板块仍有代表股跟随。研究卡写出回踩承接区和失效位；如果突破后直线拉升且没有回踩，不追。

### B. 首段启动的低位转强

个股仍在近期区间中上部以下，成交量较此前基线放大，价格推进而非只放量滞涨，且至少两个同主题标的同步。它的价值在于“尚未充分扩散”，不是单纯价格低。

### D. 提前识别而非事后追涨

所谓“预测提前会涨”，在 ACE 中定义为：在完全突破前识别出仍有预期差的结构，并提前写好确认与失效条件。可用证据包括平台收敛、相对强度先于板块扩散、竞价/前五分钟主动承接、回踩缩量后收回关键位、近 1–3 日资金连续性。它只产生条件式研究判断，不产生确定涨幅或胜率承诺。

### C. 板块二线补涨

主线已有明确催化和宽度，龙头/前排确认后，选择尚未大幅扩散、仍有流动性的普通主板标的。若板块只剩一只涨停或跟风数量快速减少，补涨逻辑失效。

## 6. 反方证据清单

每张候选卡必须主动查找至少一条不利证据，并标注 `FACT` 或 `UNKNOWN`：

- 指数转弱、涨跌家数恶化或成交额明显萎缩；
- 板块只有单一股票强，代表股不同步；
- 高开低走、长上影、放量不涨或资金流与价格方向冲突；
- 公开公告/新闻无法确认，或消息发布时间晚于观察时点；
- 当前价已逼近压力位，失效距离过小，或一手门槛/涨跌停导致难以成交；
- 论坛情绪极端但硬数据没有同步。论坛只作为分歧问题，不能替代 quote、1m、index、公告和成交数据。

## 7. 标准研究卡（交给老师，不直接发群）

```text
candidate_status: RESEARCH_ONLY | NO_SUITABLE_SETUP
as_of: Asia/Shanghai timestamp
code_name: code + verified listed name
role: 主选 / 进攻型备选 / 观察
setup: A平台回踩 | B首段转强 | C板块补涨
why_now: 预期差、板块、量价、事件四项事实
confirmation: 盘中必须出现的条件
observation_zone: 观察/触发区，不保证成交
invalidation: 结构或行为失效点
pressure: 技术观察位，不是收益目标
counter_evidence: 至少一条反方事实或 UNKNOWN
sources: 独立 source refs + snapshot hash
teacher_action: 审阅、降级或不采用
```

小群交付仍由老师最终确认、小妍负责温和转发。任何“现价即刻买入、稳赚、配合拉升、保证收益”的措辞都不属于本手册。

## 8. 验证与晋级

在进入任何 Advisor 或生产候选前，冻结规则版本并回放至少 20 个历史交易日，按时间切分训练/验证/样本外区间，保留：

- 理论成交率、滑点和一手可成交性；
- 次日可退出性、失效触发率、假突破率；
- 板块同步率、数据源冲突率、最大连续亏损；
- 每次候选的原始快照、来源、规则版本和最终人工决定。

回放没有达到预先约定的结果标准时，保留为 `RESEARCH_ONLY`，不通过改阈值来“优化”结果。历史回放也不能替代当前 ACE Phase 2 的 quote、minute_kline_1m、index 严格准入。

## 9. 推荐集成位置与明确拒绝项

**建议集成位置**：`core/early_session_research_protocol.py` 的研究输入契约、`core/market_context_research.py` 的板块/指数快照、`core/teacher_review_packet.py` 的候选卡呈现，以及 `outputs/research_briefs/` 的只读归档。

**不应安装或直接接入**：任何自动下单、自动推送、承诺收益的交易机器人；把论坛情绪当作数据源主证据；把同一上游的多个节点包装成独立来源；把论文或海外方法的周期/阈值原样搬到 A 股早盘；用旧的 Advisor 或历史报告绕过当前 Data Health/Admission。
