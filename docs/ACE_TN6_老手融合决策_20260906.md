# ACE TN6 经验融合与日级进攻判断

更新时间：2026-09-06（Asia/Shanghai）  
状态：`RESEARCH_ONLY`

## 定性

这批材料是 100 个 `.tn6` 指标包，不是 100 个已解出的公式或 100 个可直接运行的信号。ACE 不把它们包装成“神奇新号”，而是用老手的预期差→确认→可退出框架，吸收其中反复出现的交易结构：首段启动、平台突破后的第一次回踩、竞价主动性、分时承接、近 1–3 日资金连续性和板块扩散。

已经补上中间层 `core/tn6_experience_fusion.py`：它把元数据中反复出现的词整理成“待验证的结构假设”，再与明确写入的老手原则做对齐。这个中间层只回答“以后要验证什么”，不回答“现在买什么”。文件名出现次数只是样本描述，不是胜率、置信度或加分。

## 三轴必须分开

| 轴 | 含义 | 不允许的替代 |
| --- | --- | --- |
| `attack_grade` | 机会强度：A+ / A / B / C / D | 不能被风险等级直接压低 |
| `conviction` | 当前证据是否足以主动判断 | 不是胜率或收益承诺 |
| `risk_level` | 波动、隔夜、执行、事件和失效暴露 | 不能冒充机会质量 |

因此可以出现“`A+ + HIGH + HIGH`”：机会赔率值得认真看，但仓位更小、验证窗口更短、失效后更快退出。

## 每日诚实结论

`core.ultrashort_factor_profile.summarize_daily_opportunity()` 只对已经分类的研究卡做日级归纳：

- 最高卡为 A+：`A_PLUS_PRESENT`；
- 最高卡为 A：`A_PRESENT`；
- 最高卡只有 B/C/D：`NO_A_TODAY`，不把两个 B 凑成推荐；
- 没有候选卡：`NO_SUITABLE_SETUP`；
- 评级轴缺失：`GRADE_CALL_UNAVAILABLE`。

这条规则的目标不是保证每天有票，而是让 ACE 每天说出它对市场最真实、最有赔率的判断。TN6 只能提供经验先验；当前仍需实时数据、独立来源、观察/确认条件、失效条件和历史回放，保持 `RESEARCH_ONLY`。

### 老手融合的实际边界

### 4–5% 早期转强与“提前识别”

从本轮起，4–5% 的当日涨幅不再被一刀切排除。它只有在首段启动/首次回踩、板块至少两个代表同步、开盘或分时承接真实、量价仍在推进、距离压力和失效位可执行时，才进入“早期转强车道”；尾段加速、放量滞涨、板块掉队或只能追涨停时仍只做观察。

“提前会涨”在 ACE 中不是确定性预测，而是：在完全突破前，识别出平台收敛、相对强度先行、竞价/前五分钟承接、回踩缩量回收、近 1–3 日资金连续性等证据组合，并提前写好确认条件、失效条件和 1–2 日验证窗口。这个车道只改变研究呈现顺序，不改变 TN6 的 `score`、准入或收益承诺。

- TN6 结构假设可以帮助候选生成和反方问题设计，但不能改变 `score`、`attack_grade`、`conviction` 或 `risk_level`。
- 只有逐时间点的行情回放能把“文件名先验”变成可检验的规则；回放必须保留滑点、手续费、涨停无法成交、失败样本和样本外区间。
- 老手经验不是一句口号：每条原则必须写成 `rule_id`、具体陈述、适用结构和反例问题；没有反例验证就标记 `EXPERIENCE_TO_VALIDATE`。
- 这条链的最终顺序固定为：`TN6样本 → 结构假设 → 老手原则对齐 → 当前盘面确认 → 失效/退出 → 历史回放`。任何一步缺证据，都只能停留在 `RESEARCH_ONLY`。
