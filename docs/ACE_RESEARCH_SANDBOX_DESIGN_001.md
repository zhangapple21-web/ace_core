# ACE 研究沙箱 v1

状态：`RESEARCH_ONLY`

## 目标

用可审计、可回放、不可偷看未来的数据增强老师判断；在样本外和实盘样本验证完成前，不替代老师、不生成正式荐股、不自动下单。

## 三层结构

```text
因子进化实验室
    → 市场状态 / 策略工厂
    → 风险预算 / 拥挤度过滤
    → 老手观察
    → 老师最终判断
```

第一版只提供纯函数和快照契约，输入必须携带观察时间与来源引用。研究记录写入快照时保留 `snapshot_sha256`、证据完整性和降级原因。

## 当前已落地的流水线骨架

- `core/research_data_adapter.py`：行情与日线适配器，保留 provider、symbol、时间和证据状态；不负责排名或荐股。
- `core/research_ingest.py`：单标的点时采集入口，生成行情特征并写入哈希快照；板块、资金、公告未接入时强制标记 `UNVERIFIED`。
- `core/research_pipeline.py`：四类证据容器、确定性种子因子、滚动样本外汇总和研究快照组装。
- `core/research_sandbox.py`：市场状态、CVaR、拥挤度及 `write_snapshot` 哈希校验。

因子候选目前是可解释的基线种子，不宣称遗传算法或强化学习已经发现有效策略。只有在真实数据源通过审计、滚动样本外和独立实盘样本验证后，才允许由老师人工决定是否接入荐股流程。

单标的采集入口（仅研究态）示例：

```text
py -3 -c "from core.research_ingest import ingest_symbol_snapshot; print(ingest_symbol_snapshot('000001', output_dir='research_records')['write'])"
```

若运行环境的外部访问闸门关闭，入口应失败并保留原因；不得改用未经标注的模拟数据填充实盘字段。

## 防未来函数与回测边界

- 所有特征按可获得时间截断；公告按披露时间而非报告期时间进入样本。
- 使用滚动/走步样本外验证，保留训练、验证、测试边界。
- 回测必须计入佣金、滑点、涨跌停、停牌、T+1、容量和成交不可得性。
- 禁止幸存者偏差、后复权偷看、未来成分股名单和事后补录席位。
- 失败、冲突和缺失保持 `UNKNOWN` / `INCOMPLETE_GAPS`，不得静默填补。

## 输出边界

研究沙箱允许输出：因子候选、市场状态、CVaR、拥挤度、假设、验证条件和风险提示。

研究沙箱不允许输出：自动买卖指令、目标收益保证、自动 Telegram 外发、Advisor/Risk 晋级或正式荐股结论。

## 进入正式荐股前的门槛

1. 至少一段完整样本外窗口；
2. 至少一个独立实盘样本窗口；
3. 结果含交易成本、流动性和回撤分布；
4. 老师复核“方向正确但时机错误”等失败类型；
5. 风险预算、拥挤度和数据健康全部通过；
6. 明确记录人工批准和回滚条件。

`2%` 只能作为待验证的风险目标或阈值，不能写成系统保证。
