# ACE 时效与小群表达固化（v1）

更新时间：2026-09-08（Asia/Shanghai）
状态：`RESEARCH_ONLY`；本规则不改变金融数据准入、Advisor、Risk 或 Telegram 外发权限。

## 为什么补这一层

兴森科技在涨幅约 9.20% 后才送达、黑猫在 10:10 已封板才送达，说明“方向判断正确”不等于“客户仍可执行”。因此候选除了判断轴，还必须记录消息时效和窗口状态。

## 时效规则

- 快照距离当前超过 10 分钟：`STALE_SNAPSHOT`，先刷新，禁止写入进场语言。
- 个股涨幅达到 9% 或以上：`LATE_HIGH_MOVE`，只写“等待回踩/下一机会”；不得写“上车”。
- 已封板或无法成交：`WINDOW_MISSED`，等待开板或次日新结构。
- 4–8% 的早期转强：`EARLY_MOVE_CONFIRMABLE`；只有板块联动、首段承接和量价确认齐备，才进入人工观察。
- 所有状态都不参与打分，不能改变 `attack_grade`、`conviction` 或 `risk_level`。它只约束消息能否使用“进场/介入”措辞。

实现：`core/trade_timing.py` 的 `assess_trade_window()`。

## 小妍小群话术

对外表达采用“主选 + 进攻型备选”的机构节奏：先给结论，再给定位和为什么现在，最后给确认/失效。语气可以坚定、专业、利落，体现团队已经筛过一轮；信心来自事实、赔率和条件，不来自必涨承诺。

若窗口已过，明确告诉群里“这条不追，等回踩/等下一结构”，不把事后上涨包装成当时仍能买。若当天最高只有 B，直接说“今天没有 A”，不为完成两只配额凑票。

TN6 仍是 `context_only` 的结构借鉴，不是信号源；小妍文案不展示内部字段，也不绕过 `RESEARCH_ONLY`。
