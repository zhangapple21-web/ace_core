# R1 生态宪法种子（自由区）

这不是 R1 代码的复活，也不是 ACE 生产配置。它是从 R1/R2 设计中压缩出的 `DESIGN_SEED`，放在 `07_SANDBOX/free_research/constitution/`，供后续实验引用。

## 这次真正保留的东西

- **航线**：观察 → 问题 → 假设 → 实验 → 反例 → 证据 → 蒸馏 → 治理 → 提案 → 复查。
- **生态**：自由区可以从本地历史、宪法、失败和 inbox 中自主觅食，自动判断、领取并运行不成熟、相互冲突甚至失败的假设；馆长事后整理，法院只在出界处验真，老师只审阅后置产物，生产链仍由原有门禁决定。
- **连续性**：船长、模型、Runtime 可以替换，但路由、证据血缘和不可逾越的边界不能丢。
- **反例价值**：旧的死循环、空实现、错误数据和未兑现设计不是羞耻材料，而是下一轮实验的反面教材。
- **压缩而非搬运**：只吸收设计语义，不把历史脚本、人格、定时器、推荐或外发路径复制进 ACE。

## 为什么不是“所有东西都接进来”

R1 的自由并不等于生产权限。自由区的自由是提出假设、保留失败、比较多种解释并自行执行隔离实验；它的现实出口仍是一条单向的 `PROPOSAL_ONLY` 边。自由区实验不需要先经过这些门；任何真实采用才必须重新经过当前证据、Validator、Admission 和 Risk。

## 与现有 ACE 的关系

| R1 设计语义 | 当前自由区实例 |
| --- | --- |
| 自由区 / 多宇宙 | 独立实验记录；竞争假设不覆盖彼此 |
| 五大加工关系 | `factories/` 中的回收线、标记、直接/反例世界蓝图、加工回执、公开外部快递回执；熔炼厂随后把所有结果蒸馏 |
| 废墟熔炼厂 | `FreeResearchSandbox.distill` |
| 孟婆 / 遗忘层 | quarantine + stale/pollution 标记，不删除历史 |
| 馆长 / 法院 / 老师 | `SandboxSociety` 的后置整理、边界验真、结果审阅角色 |
| 24 小时学习 | 每日自主觅食、领取和执行窗口；没有新食物时写明 `NO_NEW_FREE_ZONE_WORK` |

当前系统已经有足够的“船体”：唯一 ACE daemon、自由区、法院和提案边界。这里补的是航海图，而不是再造一艘船。

五大工厂的“仿造”只生成互相竞争的研究世界蓝图，不生成虚构市场事实；“线”是不可变的来源与研究形状记录；“快递员”只能把公开、无凭据的材料带回自由区。孟婆的自动陈旧化策略仍未实现——现阶段只保留 quarantine/stale 标记而不删除任何线，直到有单独的保留期限与反证回收合同。
